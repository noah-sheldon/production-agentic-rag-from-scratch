# Code of Conduct

Be kind, be honest, build together.

- No harassment, discrimination, or personal attacks — of any kind, for any reason.
- Feedback on code is feedback on code, never on the person. Disagreement is welcome; disrespect is not.
- Credit others' work. Originality is a course rule; plagiarism ends contributions.
- Help beginners. This course is built for people who have never seen a terminal.

Violations: report privately to the maintainer. Repeated violations end in removal.
