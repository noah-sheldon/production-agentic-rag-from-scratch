# Artifact — the per-step breakdown checklist

Make any RAG answer measurable:

- [ ] Wrap every step (retrieve, prompt, answer) in a named timer
- [ ] Record: name, start, end, duration (ms)
- [ ] Print a breakdown sorted by duration with % of total
- [ ] Know your baseline — where does the time go today?
- [ ] Re-measure after every change — never optimize what you can't see
- [ ] When one step dominates, that's the step to fix first
